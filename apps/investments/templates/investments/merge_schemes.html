🔀 Merge Schemes

For AMC mergers (e.g. an old scheme absorbed into a new one) — moves the closed scheme's transaction history onto the surviving scheme so XIRR can span the merger.

← Dashboard
→

Note: unit counts aren't carried over — AMC mergers reallot units based on the NAV ratio at merger time (value-preserving, not unit-count-preserving), so only the dated transaction history (rupee cashflows) is moved. The surviving scheme's own invested/current value is left untouched.
