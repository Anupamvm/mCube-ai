📖 What is mCube?

mCube is a sophisticated algorithmic trading system designed for the Indian stock market. It provides automated trade execution, real-time analytics, risk management, and AI-powered insights to help you make better trading decisions.

The platform integrates with major Indian brokers (Kotak Neo, ICICI Breeze) and supports multiple trading strategies including Futures trading, Nifty Strangles, and Iron Condors.

🚀 Quick Start Guide

Get up and running with mCube in minutes

1

Configure Broker Credentials

Navigate to System Configuration and enter your broker API credentials. mCube supports Kotak Neo (for Options) and ICICI Breeze (for Futures).

2

Authenticate with Brokers

Complete the OTP-based authentication for each broker. This enables secure API access for placing orders and fetching market data.

3

Set Risk Parameters

Configure your risk tolerance, maximum position size, and daily loss limits. This ensures the system respects your risk boundaries.

4

Execute Your First Trade

Go to Trade → Execute Trade and use one of the available algorithms: Futures Algorithm, Nifty Strangle, or Broken Iron Condor.

💡

Pro Tip

Start with paper trading or small positions to familiarize yourself with the system before scaling up.

🛡️ Risk Management

Protecting your capital with smart controls

🎯 Risk Controls

mCube implements multiple layers of risk management to protect your trading capital:

Control Type Description Default
Position Sizing Automatic calculation based on account size and risk percentage 2% per trade
Stop Loss Automatic stop-loss placement for all positions Technical levels
Daily Loss Limit Maximum daily loss before trading is paused 5% of capital
Margin Utilization Maximum margin usage threshold 80%
Circuit Breaker Halt trading on consecutive losses 3 losses
✅

Risk Best Practices

Never risk more than 2% of your capital on a single trade. Use the position sizing calculator to determine appropriate lot sizes.

📊 Futures Algorithm Scoring

Factor Weight Description

Key API endpoints used by the trading engine:

Authentication Required
