How to get Session Token Manually

  1. Go to: https://api.icicidirect.com/apiuser/login
  2. Login with your ICICI Direct credentials
  3. Enter the OTP sent to your registered mobile
  4. After successful login, you'll be redirected to a URL like:
    https://127.0.0.1/?apisession=XXXXXXXX
  5. Copy the value after apisession= and paste it above
  6. Note: Session tokens expire daily and must be refreshed each day

Setup Auto-Login

To enable automated login (fills credentials, you only enter OTP):

  1. Ensure your Breeze credentials are stored in the database
  2. Run: python manage.py setup_credentials --setup-breeze
  3. When prompted, enter your:
    • API Key (from ICICI API portal)
    • API Secret
    • ICICI Direct User ID (login username)
    • ICICI Direct Password
  4. Chrome browser must be installed on this machine
